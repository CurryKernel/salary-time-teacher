# salary-time（教师版）

一个面向教师的 Windows 桌面工资悬浮窗：**实时显示今天、此刻已经挣了多少钱**，同时统计本月、本周累计收入。收入由「基本工资 + 房补 + 课时绩效」组成，课时费按上午 / 下午的节数和系数计算。

## 功能

- **今日已赚**：按当天上班时间实时跳动，精确到分；午休冻结，下班后保持满额。
- **本月累计 / 本周累计**：从月初 / 本周一累计到当前时刻，包含课时费，并显示预计收入和进度条。
- **课时绩效**：分别设置上午、下午的节数和系数，默认每天 6 节课、每节 35 元、系数 1.0。
- **固定收入**：基本工资与房补按当月工作日摊到每一天。
- **双休**：周末不计薪，没有月末周六、没有加班费。
- **桌面体验**：无边框圆角悬浮窗、拖动、置顶、隐藏到托盘、一键退出、开机自启动、设置自动保存。

## 默认参数

| 参数 | 默认值 |
| --- | --- |
| 基本工资 | ¥10,000 / 月 |
| 房补 | ¥1,000 / 月 |
| 课时单价 | ¥35 / 节 |
| 上午课程 | 3 节，系数 1.0 |
| 下午课程 | 3 节，系数 1.0 |
| 每天课时 | 6 节 |
| 上班时间 | 08:20 |
| 午休 | 11:40 – 14:20（不计薪） |
| 下班时间 | 16:30 |
| 休息日 | 周六、周日 |

以上金额均为默认值，可在设置中按实际情况修改。系数可输入 `0.8`、`0.9`、`1.0` 等数值。

## 计算规则

```
计薪天数   = 当月周一至周五的天数
固定日薪   = (基本工资 + 房补) ÷ 计薪天数
课时费/天  = (上午节数 × 上午系数 + 下午节数 × 下午系数) × 课时单价
日合计     = 固定日薪 + 课时费/天
今日已赚   = 日合计 × 当日工时进度（午休冻结，下班满额）
本月累计   = 本月已过工作日的日合计之和（今天按进度折算）
本周累计   = 本周一至当前时刻的日合计之和
本月预计   = 基本工资 + 房补 + 计薪天数 × 课时费/天
```

以默认参数、21 个工作日的月份为例：

- 固定日薪：`(10000 + 1000) ÷ 21 = ¥523.81`
- 课时费：`(3 × 1.0 + 3 × 1.0) × 35 = ¥210.00`
- 日合计：`¥733.81`
- 本月预计：`10000 + 1000 + 21 × 210 = ¥15,410.00`

上午系数改成 `0.9` 后：课时费 = `(3 × 0.9 + 3 × 1.0) × 35 = ¥199.50`。

## Windows 安装

在 `dist/` 目录中：

| 文件 | 说明 |
| --- | --- |
| `salary-time-Setup-1.0.0.exe` | 安装版，可选安装目录，创建「salary-time 教师版」桌面快捷方式 |
| `salary-time-Portable-1.0.0.exe` | 免安装便携版，双击即用 |

> 程序未做商业代码签名，首次运行 Windows SmartScreen 可能提示「Windows 已保护你的电脑」，点击「更多信息 → 仍要运行」即可。

系统要求：Windows 10 / 11（x64）。

## 使用

| 操作 | 说明 |
| --- | --- |
| 拖动标题栏 | 移动悬浮窗，位置自动记住 |
| 图钉按钮 | 始终置顶 |
| 齿轮按钮 | 打开设置，修改后自动保存 |
| 减号按钮 | 隐藏到系统托盘 |
| × 按钮 | 退出应用 |
| 托盘 ¥ 图标 | 显示 / 隐藏；右键退出 |
| `Esc` | 从设置返回主界面 |

设置项：

- **薪资设置**：基本工资、房补、课时单价
- **课时绩效**：上午节数 / 系数、下午节数 / 系数
- **工作时间**：上班、下班、午休开始 / 结束
- **系统**：始终置顶、开机自启动

## 开发与打包

```bash
npm install
npm start        # 本地运行
npm test         # 计薪单元测试（15 项）
npm run test:ui  # UI 冒烟测试（38 项断言，需要桌面环境）
npm run dist:win # 打包 Windows 安装包 / 便携版
```

在 macOS / Linux 上交叉打包 Windows 版本：

```bash
export ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"
npx electron-builder --win --x64
```

如果下载 Electron 失败，可设置 `ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"`。

产物在 `dist/`：

- `salary-time-Setup-1.0.0.exe`
- `salary-time-Portable-1.0.0.exe`
- `SHA256SUMS-1.0.0.txt`

## 说明与限制

- 课时费在「今日已赚 / 本月累计 / 本周累计」中都会计入；它跟固定工资一样按当天工作进度平滑累计，而不是按每节课上完才结算。
- 未内置法定节假日日历，计薪天数按当月周一至周五统计；如遇学校特殊安排，可在后续版本扩展。
- 基本工资和房补是月固定收入，按当月工作日摊到每天；周末和午休不计薪。
- 本应用与通用版 `salary-time` 是两个独立目录，互不影响。
